# In-Browser File Encrypter — Claude Version

## Attention!

This application hasn't undergone an independent security audit and hasn't had its cryptographic engine tested. **Use it at your own risk!**

Made by Claude using the code of the [In-Browser-File-Encrypter](https://github.com/Northstrix/In-Browser-File-Encrypter)
